# FT4A Leden (ft4a.com)

WordPress-plugin met de volledige website van ft4a.com (18 talen), ledenomgeving, verkoop van de pakketten, ledendatabase en SEO.

- `ft4a-leden.zip` – de nieuwste versie van de plugin
- `update.json` – versie-informatie; ft4a.com controleert dit bestand en werkt de plugin automatisch bij

Nieuwe versie: zip vervangen en `version` in `update.json` verhogen. De site haalt de update binnen enkele uren op, of meteen via FT4A → Nu bijwerken.
